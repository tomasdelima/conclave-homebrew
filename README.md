# Conclave Homebrew

Original homebrew for the revised fifth edition of Dungeons & Dragons, developed within a cohesive world and organized as portable homebrew JSON for compatible digital toolsets.

This repository is an evolving creative project. Its structure supports consistent authoring, revision, and distribution as the project grows.

## Getting started

Open `index.html` in a browser to view the local preview. Use the generated exports in `homebrew/` to load the project through the homebrew import interface of a compatible toolset.

For file layout, import instructions, and build checks, see the [usage guide](docs/usage.md). Contributor guidance is in [AGENTS.md](AGENTS.md).
